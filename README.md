Дүгнэлт 

 FAIL ба DOWN ажиллуулалтаар oracle-ийн алдаа ба холболтын алдааны ялгааг бодитоор харсан. Тестүүд серверээс согог олоогүй. Server.js уншихад status талбарт inactive биш ямар ч утга ирвэл оюутныг идэвхгүй гэж үздэг сул тал анзаарагдсан. Postman дээр ногоон байсан ч export хийхэд baseUrl хоосон болж, Newman дээр унасан тул хоёр хэрэгслийн үр дүнг тусад нь шалгах хэрэгтэйг ойлгосон. Folder хуулахдаа хуучин ID-гаа солихоо мартахад тест буруу шалтгаанаар унасан. Талбарын нэрийг буруу бичихэд сервер алдаа өгөлгүй буруу алдааны код гаргасан. Хамгийн их бодол шаардсан нь тестийн утгуудыг сонгож хослуулах байсан. Оюутан эсвэл хичээл байхгүй үед түүний үзсэн хичээл, урьдач нөхцөл гэж юу ч байхгүй тул тэдгээрийг хослуулж тестлэх боломжгүй байсан.
